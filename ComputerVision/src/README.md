# Source Code (`src/`)

Danh sách các file cài đặt thuật toán của 3 thành viên:
- **Kỹ thuật 1 (Người 1 — CLAHE):** `P1_CLAHE.py` (`clip_histogram`, `build_tile_luts`, `clahe`)
- **Kỹ thuật 2 (Người 2 — Ngưỡng thích nghi):** `P2_Adaptive_Threshold.py` / `integral_threshold.py` (`integral_image`, `box_sum`, `local_mean_std`, `adaptive_threshold`)
- **Kỹ thuật 3 (Người 3 — Hough đa tỉ lệ):** `P3_Hough_Transform.py` / `Hough.py` (`hough_accumulate`, `find_peaks`, `hough_multiscale`)
