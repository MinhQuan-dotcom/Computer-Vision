# Computer Vision — Group Project

## Structure
- `src/`: implementation files written by the assigned group members.
- `tests/`: test cases and test results.
- `experiments/`: experiment notebooks, plots, and parameter sweeps.
- `images/`: input and synthetic images used in experiments.
- `docs/`: assignment notes, checklists, and team decisions.
- `main.ipynb`: shared notebook for final integration and end-to-end execution.

## Suggested workflow
1. Each implementation owner commits their own code to `src/`.
2. Keep experiments and plots in `experiments/`.
3. Record actual test results in `tests/`.
4. Before submission, restart the notebook kernel and run `main.ipynb` from top to bottom.

## Important
This is only a starter folder structure. It does not contain the required algorithm implementations.
Follow the assignment's rules on permitted libraries and AI usage.
